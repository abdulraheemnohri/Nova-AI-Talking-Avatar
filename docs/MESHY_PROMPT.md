# Meshy prompt — Nova

Create an original realistic adult humanoid virtual assistant named Nova, full body, neutral A-pose, facing forward, anatomically plausible proportions, silver-ash hair tied back, blue-gray eyes, friendly calm expression, realistic but tasteful skin detail, detailed hands and fingers, tailored white and charcoal futuristic suit with restrained cyan accents and a small geometric chest emblem. Clean studio lighting, neutral background, clear separation of limbs, no props, no dramatic pose, no cropped body parts. Build clean deformation-friendly geometry suitable for a humanoid rig and mobile real-time rendering. Target a textured GLB with PBR materials. Keep the design original and do not imitate any identifiable person or copyrighted character.

## Production steps
1. Generate textured humanoid in A-pose and inspect the preview.
2. Download GLB and preserve the task ID / project history.
3. Check topology and face count before rigging.
4. Rig the textured humanoid; inspect joint hierarchy and deformation.
5. Query the animation catalog for supported clips; only claim clips actually exported.
6. Test GLB, skinning, clips, and morph targets in the chosen runtime.
7. If facial morph targets/visemes are absent, create them in Blender or another facial-rigging tool. Do not assume Meshy rigging automatically supplies a complete facial blend-shape set.
